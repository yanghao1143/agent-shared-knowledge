## 400 Error: tool_use/tool_result 不配对

**问题**：工具调用中断时，`tool_use` 保存了但 `tool_result` 丢失，下次 API 调用返回 400

**根因**：Anthropic API 要求每个 `tool_use` 必须有对应的 `tool_result`

**原因链**：工具调用中断 → tool_use 写入历史 → tool_result 没写入 → API 拒绝

**临时方案**：遇到 400 直接 `/new` 开新会话

**永久方案**：OpenClaw 应在发送前验证配对，失败时写入 error tool_result

**Issue**: 待提交到 OpenClaw repo

## Browser: Snap Chromium AppArmor 限制

**问题**：Snap 版 Chromium 无法访问 `~/.openclaw/browser/`

**根因**：AppArmor 限制 snap 应用只能访问特定路径（如 `~/snap/chromium/`）

**错误信息**：`Failed to create SingletonLock: Permission denied`

**解决方案**：

1. **推荐**：用 apt 版 `/usr/bin/chromium-browser`
2. **Workaround**：手动启动 CDP + cdpUrl 连接

```bash
chromium-browser --headless --no-sandbox --remote-debugging-port=18800 \
    --user-data-dir=$HOME/snap/chromium/common/openclaw-browser &
```

配置：`"browser": { "cdpUrl": "http://127.0.0.1:18800" }`

**脚本**：`scripts/start-chromium-cdp.sh`

## Tool Call Style

**教训**：常规工具调用直接执行，不需要叙述

**错误**："There is a tool use." → 然后调用工具

**正确**：直接调用工具，结果出来再说

遵守 AGENTS.md 指导：低风险操作直接调用，只在复杂/敏感操作时叙述
