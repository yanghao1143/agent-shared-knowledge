## A/B 测试：工具调用策略

### 测试结果
- **方案 A**（预检）：5 次调用，1 次失败
- **方案 B**（不预检）：4 次调用，0 次失败

### 关键发现
- 假预检比不预检更危险
- 凭记忆预检 = 自欺欺人
- 方案 B 的优势：错了系统会告诉你正确答案

## 多模型上下文兼容性（待研究）

### 发现
- 上下文存储位置：`~/.openclaw/agents/main/sessions/*.jsonl`
- 存储格式：Anthropic 风格 `content: [{"type": "text", "text": "..."}]`
- OpenClaw 读取时有格式兼容逻辑（string vs array）

### 问题
- Anthropic: `content: [{type: "text", text: "..."}]`
- OpenAI: `content: "string"`
- 切换模型时可能不兼容

### 待验证
- 发送给 API 时的格式转换逻辑
- 实际切换模型测试
